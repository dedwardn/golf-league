# S16d Round links on standings

**Implemented**

- Each cell of the viewer's grid on standings links to that round's page at `/rounds/{number}`, on every tab. The whole cell is the link, label and total together.
- Each row of Round winners links to its round's page. A row is at least 44 px tall and the block has no gap between rows, so the rows sit 44 px apart (the owner, at the plan). The grid cells stay as drawn.
- The links appear in either season mode. In an individual season the round page still reads "That round isn't open." until S21, as home's round links do.

**Deviations from plan**

- The winners block drops the `stack` class as well as `stack--tight`. With `.stack`'s 14 px gap the rows would sit 58 px apart rather than the 44 px the architect's ruling and the owner's answer describe. With no flex container, the block-level anchors sit edge to edge.
- The BUILD_PLAN edit also records the owner's 44 px answer in the S16d section, beside the architect's wording.

**Deliberately not done**

- The round page in an individual season, which these links open as "That round isn't open." until S21.
- "See all cards" on the round result (S20).
- `docs/design/standings.html` still draws no links, as `docs/design/home.html` draws none for home's round links (the architect, at the plan).

**Audit**

The reviewer found nothing to fix on its six checks (duplication, placement, bloat, spec fidelity, tests, stored derived data). It left three notes. The architect ruled on each:

1. **The design file still draws the tight winners block and no links.** The layout part is settled by a doc edit to `docs/design/standings.html`, so that a later rebuild from the design keeps the 44 px rows. Each winners row gets `min-height:44px`, the block loses `stack stack--tight`, and a comment explains the change. The edit is a finding about `docs/`, so it went to the owner, who approved it, and it is in this step's commit. The links part is declined, following the plan's ruling: the design draws no round links, as `docs/design/home.html` draws none.
2. **`text-decoration:none;color:var(--text)` is inline three times.** Declined. `docs/design/README.md` gives a pattern a class in `tokens.css` once it is on three screens. The exact pattern is on two, home and standings.
3. **The reviewer did not run the gate.** Closed: the builder's run exited 0 with 653 passed and 100 percent coverage.
