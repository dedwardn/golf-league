# S17d2b Admin round setup

**Implemented**

- Rounds has Add a round above its rows. It opens `/admin/rounds/new`, a new round's form headed "Round {n}". The number is one more than the season's highest round, drafts included, and is carried in a hidden field. Save round stores the round as a draft through `create_round`, with decision 6's allplay on the stableford basis at scale 10, and opens its screen.
- A draft's round card is the same form, filled as stored. Save round changes it through `change_round` and keeps its contests. An open or closed round's card reads as text with the fixed line, as before.
- The form has a tee select, with the tee's query string as each option's value, Opens and Closes in Oslo time, and five format rows. Each row reads "{name} · {allowance}" at that format's defaults and has no input. Save round stores the checked format at its defaults (decision 6, the owner at the plan).
- `create_round` now refuses a number any stored round has ("The season already has a round {n}."), so a second tap stores nothing. It also refuses a season not stored ("Set up the season before its rounds."). A refused save answers 400 with every field as typed and one warn card.
- Add a course and tee and Change a tee have a back arrow to Courses.

- `league.domain.configs.TEAM_ROUND_FORMATS: Mapping[str, FormatConfig]`

**Deviations from plan**

- **No allowance inputs.** The owner changed the plan's answer 3 at approval: each format row reads its allowance as text at the defaults. The architect ruled on that change before the build. `formats.html` is untouched, and "An allowance is a whole percent." and its tests are gone.
- **The refusal test checks Foursome, not Scramble.** The architect's ruling 13j said each refusal posts Scramble. The draft is a Scramble round, so a draft's refusal redrawn from the stored round would pass with Scramble. Foursome catches it.
- **The cookie refusal posts to a draft.** It posts to round 6, a draft it creates, rather than round 1, so a missing cookie check on the change route would store something the test sees.
- **The design tee's back arrow opens `admin-tee.html`.** The Courses list has no design file, and the design nav's Courses tab opens `admin-tee.html` too.
- **Test names** differ a little from the plan's. Each now names what the owner's change left.
- **`web/admin.py` and `typed_fields`.** `web/admin.py` was outside the plan. It changed only to import `typed_fields` from `shared.py`, after the owner approved the audit's finding 3.

**Deliberately not done**

- The state card and Open round belong to S17d3, and cards and manual awards to S17e. Contests, pairings, `late_until` and an individual season's round form belong to S21. Until S21, an individual season's Save round is refused with "an individual season's round has no format".
- No step owns deleting a draft or a check that Closes is after Opens. The architect settled the second: the window is informational.
- There is no script that disables Save round after a tap. The server's refusal keeps a second draft from being made.

**The audit**

The reviewer raised seven findings, and the architect ruled on them:
- **1, declined, with a doc edit.** Web works out the new round's number, and two GETs read the season's rounds and the stored tees. A use case for the number would add a public name for one form and remove nothing, and R13's uniqueness lives in `create_round` alone. ARCHITECTURE's web preamble now names these screens.
- **2, applied.** Decision 6's defaults moved from web's `_DEFAULTS` to `TEAM_ROUND_FORMATS` in `configs.py`, beside `TEAM_ROUND_CONTESTS`. `_FIRST` stays in web, as the screen's choice. ARCHITECTURE's configs row says so.
- **3, applied as the owner placed it.** The architect accepted making `admin.py`'s `_typed` public as `typed_fields`. `web/admin.py` was outside the approved plan, so it went to the owner. The owner moved it into `web/shared.py`, which both route modules import, so no route module imports another. `admin.py` changed no further, and `_round_form` dropped its inner reader.
- **4, applied.** `_checked_round`'s docstring no longer names a number SeasonFacts refuses.
- **5, applied.** `utc_typed` reads with `strptime` in `local_input`'s own format, so a date alone, or a time with its own offset, gets the window refusal. A test covers a date alone.
- **6, declined.** A private helper for the one repeated line in `shared.py` adds code.
- **7, applied.** This report now has its click-through section and the rulings above.
