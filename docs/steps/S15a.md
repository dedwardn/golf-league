# S15a Web foundation: link tokens, standings table

**Implemented**

- `create_app` serves the one season `LEAGUE_SEASON` names, from the file `LEAGUE_DATABASE` names, brought to the latest migration on opening.
- A personal link at `/k/{link_token}` sets a cookie holding the token and redirects to `/standings`. The token is looked up on every request, so a replaced link stops working at once.
- `/standings` shows the season table or one segment's, with a Season tab and one tab per segment: position, name and points.
- `utc_now` is the one read of the clock. `open_engine` holds the foreign keys PRAGMA, and the test database now opens the way the app does.
- `StandingsRow.points_text` gives points to one decimal, half up.
