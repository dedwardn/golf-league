# S15c Player home

**Implemented**

- A player's link now lands on home at `/`, and Home and Standings both have the Home tab.
- A team season shows one card per open round, oldest first: round number and format, time left, the tee id as heading, the close with its date, the format's line, one row per player with strokes and a "Card in" or "Not yet" pill, or one "Team" row in a shared-ball round, and a foot with "Your team needs both cards to score." and the count.
- One season card stands below the round cards and links to Standings, with position, points and gap.
- With no open round, home reads "No round is open right now." and shows the season card.
- An individual season shows the round's heading, its count and the season card, and nothing of S21's.

**Public API**

```python
# domain/facts.py
class RoundHeading:  # number: int, tee_id: str, closes_at: datetime

# domain/results.py
class HomePlayer:  # player_id: str, playing_handicap: int, card_in: bool
class HomeTeam:  # format: str, players: tuple[HomePlayer, ...], team_playing_handicap: int | None
class HomeRound:  # number: int, tee_id: str, closes_at: datetime, time_left: str,
                  # card_holders: int, card_in: bool, team: HomeTeam | None
class HomeView:  # rounds: tuple[HomeRound, ...], row: StandingsRow | None, competitors: int,
                 # team_season: bool
StandingsRow.position_text -> str
Gap.points_text -> str
Gap.position_text -> str

# domain/access.py
def holds_card(player_id: str, round_: RoundFacts, teams: Mapping[str, str]) -> bool

# domain/teams.py
def team_members(teams: Mapping[str, str]) -> dict[str, tuple[str, ...]]

# domain/home.py
def time_left(closes_at: datetime, now: datetime) -> str
def home_rounds(
    facts: SeasonFacts,
    view: SeasonView,
    headings: Sequence[RoundHeading],
    viewer_id: str,
    now: datetime,
) -> tuple[HomeRound, ...]

# store/load.py
def load_round_headings(connection: Connection, season_id: str) -> tuple[RoundHeading, ...]

# services/play.py
def home_view(engine: Engine, season_id: str, viewer_id: str, now: datetime) -> HomeView
```
