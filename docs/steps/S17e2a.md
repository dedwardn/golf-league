# S17e2a Correct a card

**Implemented**

- `SeasonFacts.round(number)` finds the season's open or closed round of a number. It was committed first, on its own, as a refactor-only commit (`14baec9`). The lookups in `round_cards.py`, `round_result.py`, `entry.py`, `bay.py`, `submit_card` and `add_manual_award` now use it.
- On an open or closed round's Cards card, each row with a counted card or team card has Correct before Void. Correct opens Check the card for that row. The screen opens filled with the card's scores, already checked, and reads "{holder}'s 18 holes". It has the admin nav with Rounds marked and a back arrow to the round's row, and it leaves out the player's closing line.
- Submit card replaces the card's hole scores through `correct_card`, which keeps its `submitted_at`, then opens the round's page on that row. A hole in error answers 400 with the screen and stores nothing. A card that no row of that round holds opens the round's page and stores nothing.

**Deviations from plan**

- `tests/web/test_admin_round_cards.py` was not in the plan. Two of its tests pin every link in a row, so adding Correct to the row changed what they read. Only those two assertions changed.
- `tests/web/test_admin_card.py` defines its own `template`, `database` and `browse` fixtures, as `test_admin_round_cards.py` does. Sharing them would need a `conftest.py`, which is outside the plan. Its `admin` fixture returns one signed-in client, since every case uses the same season.
- `web/admin_round.py` was not in the plan. It changed for audit findings 2 and 3, and BUILD_PLAN's module list for S17e2a now names it.
- `correction_entry` guards `row.card is None` and `round_ is None` beside the missing row. Both only narrow the types for pyright: a row found by its card id has a card, and it exists only for a round in the facts.

- Enter card: S17e2b. It is settled as offered only on an open round's "No card" rows (the owner, at S17e2's plan).

- A mark that a card was corrected, which SPEC does not name, and any check that the corrected scores differ from the card's.
- `locked.py` and `home.py` keep their own lookup of a round. Each reads a round named in the headings its caller loaded with the facts, so a missing one is a loud KeyError (the architect, at S17e2's plan).

**Audit**

The reviewer made nine findings, and the architect ruled on each:
1. **Declined.** The finding: `CardEntry.holder` on the player's path is an unread field and a third copy of R15's holder. The ruling: the admin's screen reads the field, and `card_entry`'s own logic decides its value, which BUILD_PLAN's Accept asks to test. Keeping it off the player's entry, or adding a helper in `access.py`, would move code without reducing it.
2. **Applied.** `_the_page_of` was defined twice. It is now public `round_page` in `admin_round.py`, and `admin_card.py` imports it.
3. **Applied.** A Cards row was found by its card id in two places. It is now `card_row` in `round_cards.py`, which `correction_entry` and the void's question both call. No new test, since both outcomes were already covered.
4. **Declined.** `CardEntry` is built twice in `entry.py`, but the two calls sit side by side and make no decision, so a builder would add lines.
5. **Applied.** "No query means not yet checked" was decided in two routes. It is now `query_scores` in `shared.py`, and the reader of the 18 fields is private again.
6. **Declined.** The None scores are dropped in `web`. `correct_card` takes whole scores (S14c), and `web` narrows input that has already been checked.
7. **Declined.** `here` is set on the player's screen too, where nothing reads it. Wrapping it changes nothing anyone sees. If S17e2b builds the row fragment a third time, its plan says where that lives.
8. **Settled with a SPEC edit.** SPEC's Notice row now says that a page or action under a round's page that the round does not allow stores nothing and shows the round's page, which reads "No such round." for a round the season does not have. No code change.
9. **Applied.** The SPEC sentence is listed with commit `acc9dab`, and this section and the deviation for `admin_round.py` are added.
